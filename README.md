# LM317 Adjustable Power Supply

This project is an adjustable DC power supply designed using the LM317 linear voltage regulator in KiCad.

## Features
- Adjustable DC output voltage using LM317
- Voltage adjustment through potentiometer
- Input and output filtering capacitors for stable operation
- LED power indication
- Screw terminal connectors for easy interfacing
- PCB designed and routed using KiCad

## Applications
- Electronics prototyping
- Embedded system development
- Arduino/ESP32 projects
- Laboratory power supply applications

## Tools Used
- KiCad (Schematic & PCB Design)
